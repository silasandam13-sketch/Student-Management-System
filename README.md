# GCTU QR Attendance System

A C++ console-based attendance management system designed to help lecturers manage students, courses, and attendance records.

## 📌 About the Project

The GCTU QR Attendance System is a C++ application that provides a simple way for lecturers to manage student information and attendance.

The system includes a lecturer login, student registration, course management, attendance management, student searching, student editing, student deletion, and attendance statistics.

Student, course, and attendance information can be stored in text files so that data can be loaded when the application starts.

## 📂 Data Storage

The application uses text files to store information.

Examples include:

```text
students.txt
courses.txt
attendance.txt
```

This allows information to be loaded when the program starts instead of keeping everything only in memory.

## ▶️ How to Run

### Requirements

You need a C++ compiler such as:

* MinGW
* GCC
* Visual Studio
* Code::Blocks
* Visual Studio Code with a C++ compiler

### Steps

1. Clone or download this repository.
2. Open the project in a C++ development environment.
3. Compile `main.cpp`.
4. Run the resulting program.
5. Log in using the configured lecturer credentials.
6. Use the menu to manage students, courses, and attendance.

## 🔑 Login

The current development version uses a lecturer login system.

The default credentials configured in the source code are:

```text
Username: admin
Password: gctu123
```

> **Note:** These credentials are included for development/testing purposes only. A production system should store passwords securely rather than hard-coding them in the source code.
